📋字段设置说明

创建笔记类型时，请确保包含以下字段（名称必须完全匹配）：

汉字
用于显示汉字本身，建议单字
拼音
对应汉字的拼音，支持带声调符号
音节
用于音频文件名的拼音音节，如“shi”
声调
用于音频文件名的数字声调 1-4
笔画
笔画演示内容，通常为图片或SVG
备注
补充解释、例词或语境说明

🛠️快速使用指南

  1. 创建笔记类型：在 Anki 中创建“汉字学习卡片”笔记类型
  2. 设置字段：添加“汉字、拼音、音节、声调、笔画、备注”六个字段
  3. 导入模板：将本目录中的 HTML 与 CSS 复制到模板
  4. 添加内容：为每张卡片填充汉字、拼音与笔画演示
  5. 开始学习：生成卡片并开始练习认读与发音
