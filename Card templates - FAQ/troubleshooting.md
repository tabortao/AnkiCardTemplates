# 🔧 故障排除指南

## 常见错误及解决方案

### ❌ 错误1：「已找到{{#音频}}，但字段音频不存在」

**原因：** 你的笔记类型中没有创建 `音频` 字段

**解决方案：**
1. 打开Anki → 浏览 → 选择你的笔记类型
2. 点击"字段..."按钮
3. 点击"添加"按钮，输入 `音频`（注意大小写）
4. 点击"确定"保存

### ❌ 错误2：「未找到图片字段」

**原因：** 你的笔记类型中没有创建 `图片` 字段

**解决方案：**
1. 打开Anki → 浏览 → 选择你的笔记类型
2. 点击"字段..."按钮
3. 点击"添加"按钮，输入 `图片`（注意大小写）
4. 点击"确定"保存

### ❌ 错误3：「卡片模板存在错误」

**原因：** 模板中使用的字段名称与你创建的字段名称不匹配

**解决方案：**
确保你的笔记类型包含以下**所有**字段：
- `图片` （需要手动添加）
- `音频` （需要手动添加）
- `句子` （需要手动添加）
- `翻译` （需要手动添加）

## 🎯 完整解决步骤

### 步骤1：检查现有字段
1. 打开Anki
2. 点击"浏览"按钮
3. 在左侧找到你的笔记类型（如"图片问答-Tabor"）
4. 点击"字段..."按钮查看现有字段

### 步骤2：添加缺失字段
对于每个缺失的字段：
1. 点击"添加"按钮
2. 输入字段名称（严格按照大小写）：
   - `图片`
   - `音频` 
   - `句子`
   - `翻译`
3. 点击"确定"

### 步骤3：验证字段
确保你的字段列表包含：
```
✅ 图片
✅ 音频  
✅ 句子
✅ 翻译
```

### 步骤4：保存并测试
1. 点击"关闭"保存字段设置
2. 尝试创建一张新卡片测试
3. 如果还有错误，重复上述步骤

## 💡 预防措施

1. **字段名称区分大小写**：`音频` ≠ `Audio`
2. **不要删除字段**：即使暂时不用，也要保留
3. **按照模板要求**：严格按照README中的字段列表创建
4. **测试新卡片**：创建字段后立即测试一张卡片

## 🆘 仍然有问题？

如果按照上述步骤操作后仍有问题：

1. **重新创建笔记类型**：
   - 管理 → 添加 → 基础
   - 命名为"英语学习卡片-新"
   - 按照README添加所有字段

2. **导入模板**：
   - 复制 `front_template.html` 内容到正面模板
   - 复制 `back_template.html` 内容到背面模板  
   - 复制 `styles.css` 内容到样式

3. **逐步测试**：
   - 先创建一张简单卡片
   - 逐个填入字段内容
   - 确认每个字段都能正常显示

记住：**所有字段都必须存在，即使暂时为空！** 🎯
