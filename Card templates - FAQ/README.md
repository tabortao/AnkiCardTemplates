# 🎯 英语学习卡片模板

这是一个专为英语学习设计的Anki卡片模板，采用现代化设计风格，支持图片、音频、句子和翻译的完整学习体验。

## ✨ 模板特色

- 🎨 **现代化设计**：渐变背景、圆角边框、阴影效果
- 📱 **响应式布局**：完美适配手机和电脑端
- 🌙 **黑暗模式支持**：自动适应系统主题
- 🎵 **多媒体支持**：图片展示、音频播放
- 🌟 **动画效果**：丰富的交互动画和装饰元素
- 🎯 **学习导向**：清晰的内容分区和视觉层次

## 🔥 重要：字段设置

**⚠️ 必须按照以下步骤创建字段，否则会出现字段不存在错误！**

在Anki中创建笔记类型时，请**必须**创建以下所有字段：

| 字段名称 | 用途 | 是否必需 | 创建步骤 |
|---------|------|----------|----------|
| `图片` | 图片内容 | ✅ 必需创建 | 点击"添加字段"按钮创建 |
| `音频` | 音频文件 | ✅ 必需创建 | 点击"添加字段"按钮创建 |
| `句子` | 句子或文本内容 | ✅ 必需创建 | 点击"添加字段"按钮创建 |
| `翻译` | 翻译或答案 | ✅ 必需创建 | 点击"添加字段"按钮创建 |

### 📋 创建字段的详细步骤：

1. **打开Anki** → 点击"添加"按钮
2. **选择笔记类型** → 点击"管理"按钮
3. **添加新笔记类型** → 点击"添加"→ 选择"基础"→ 命名为"图片问答-Tabor"
4. **添加字段**：
   - 点击"字段..."按钮
   - 依次添加：`图片`、`音频`、`句子`、`翻译`
   - 每次点击"添加"按钮，输入字段名称（区分大小写）
5. **保存设置** → 点击"关闭"

**⚠️ 重要提醒：** 
- 字段名称必须**完全一致**（区分大小写）
- 即使某个字段暂时不用，也必须创建，否则模板会报错
- 不需要的字段可以留空，但必须存在

## 📋 字段设置指南

### 必需字段
在Anki中创建笔记类型时，请添加以下字段：

1. **图片** - 图片内容
2. **音频** - 音频文件
3. **句子** - 英文句子或文本内容
4. **翻译** - 中文翻译或答案

### 字段使用方法

#### 图片字段
- **用途**：显示学习相关的图片内容
- **支持内容**：JPG、PNG、GIF、SVG等格式
- **图片添加方法**：
  1. 在Anki编辑器中点击"附件"按钮（📎）
  2. 选择要添加的图片文件
  3. 图片会自动插入到字段中
  4. 可以调整图片大小和位置

#### 音频字段
- **用途**：播放英文发音或相关音频
- **支持内容**：MP3、WAV、OGG等音频格式
- **音频添加方法**：
  1. 在Anki编辑器中点击"附件"按钮（📎）
  2. 选择音频文件
  3. 音频会以 `[sound:filename.mp3]` 格式插入

#### 句子字段
- **用途**：显示英文句子或需要学习的文本
- **支持内容**：文字、HTML格式
- **建议**：保持句子简洁明了，便于记忆

#### 翻译字段
- **用途**：显示中文翻译或答案解释
- **支持内容**：文字、HTML格式
- **建议**：提供准确的翻译和必要的解释

### 📸 图片使用最佳实践

1. **图片格式**：支持 JPG、PNG、GIF、SVG 等常见格式
2. **图片大小**：建议单张图片不超过 2MB，确保加载速度
3. **图片尺寸**：推荐 800x600 像素以内，保证在各设备上正常显示
4. **图片质量**：选择清晰、对比度高的图片，便于学习识别

### ⚠️ 重要提醒

- **字段名称**：必须严格按照上述名称创建，区分大小写
- **字段顺序**：建议按 图片 → 音频 → 句子 → 翻译 的顺序创建
- **内容要求**：所有字段都可以留空，模板会显示相应的占位符
- **模板兼容**：此模板专为上述字段结构设计，请确保字段名称正确

1. **打开Anki软件**
2. **创建新的卡片类型**：
   - 点击 "工具" → "管理笔记类型"
   - 点击 "添加" → "添加：基本"
   - 输入名称：`问答卡片-小学男生版`

3. **添加字段**：
   - 点击 "字段..." 按钮
   - 按照上表添加所需字段

4. **设置卡片模板**：
   - 点击 "卡片..." 按钮
   - 将 `front_template.html` 的内容复制到"正面模板"
   - 将 `back_template.html` 的内容复制到"背面模板"
   - 将 `styles.css` 的内容复制到"样式"

## 📖 使用方法

### 创建新卡片
1. 点击 "添加" 按钮
2. 选择 "问答卡片-小学男生版" 类型
3. 填写相应字段：
   - **图片**：上传相关图片（可选）
   - **音频**：添加音频文件（支持mp3、wav等格式）
   - **句子**：输入英文句子或文本内容
   - **翻译**：输入中文翻译或答案

### 字段填写示例
```
图片: [上传一张苹果的图片]
音频: [sound:apple.mp3]
句子: This is a red apple.
翻译: 这是一个红苹果。
```

## 🎨 自定义选项

### 修改颜色主题
在 `styles.css` 中找到以下部分进行修改：

```css
/* 主背景渐变 */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* 强调色 */
color: #FFD700; /* 金黄色 */

/* 区域背景色 */
background: rgba(255, 107, 107, 0.3); /* 红色半透明 */
```

### 调整动画速度
```css
/* 修改动画持续时间 */
animation: pulse 2s infinite; /* 2s改为其他数值 */
```

## 🔧 故障排除

### 常见问题

1. **图片不显示**
   - 确保图片格式正确（jpg、png、gif）
   - 检查图片文件是否已正确导入到Anki

2. **音频无法播放**
   - 确保音频格式正确（mp3、wav、ogg）
   - 音频文件名格式：`[sound:filename.mp3]`

3. **样式显示异常**
   - 检查CSS代码是否完整复制
   - 确保没有多余的字符或格式错误
