# ANKI 卡片模板

- `GushiCard`为古诗词卡片模版。
- `EnglishWordCard`为英文单词卡片模版。
- `HanziCard`为汉字卡片模版。
- `AICard_英语单词`为AI单词卡片模版。

## 如何使用

1. 打开 ANKI 软件，点击浏览，选择要修改的内容，点击`字段`，添加字段内容，与模版中的字段对应。

![添加字段](docs\image\添加字段.png)

2. 点击卡片，复制`front_template.html`到`正面模板内容`，复制`back_template.html`到`背面模板内容`，复制`styles.css`到`样式`。

![卡片模板修改](docs\image\卡片模板修改.png)
