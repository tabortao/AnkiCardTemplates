🛠️快速使用指南

  1. 创建笔记类型：在 Anki 中创建“古诗卡片”笔记类型
  2. 设置字段：添加“序号、诗名、作者、朝代、古诗内容、古诗解读、创作背景、作者简介”字段
  3. 导入模板：将本目录中的 HTML 与 CSS 复制到模板
  4. 添加内容：为每张卡片填充对应字段，建议为“古诗内容”使用多行
  5. 开始学习：在正面点击按钮进入遮盖挑战，背面查看完整解析
