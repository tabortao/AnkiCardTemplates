# 常见问题

### 显示图片后面的倒计时秒，在一些老版本手机客户端不能正常倒计时，点击“显示图片”没法显示图片，但是背面可以正常显示图片

> 需要考虑对老版本手机客户端的兼容性问题。
- 导致老旧手机客户端（尤其是较老版本的 Android WebView / AnkiDroid）出现**“倒计时不走”、“点击按钮无法显示图片”**的原因通常有两个：
JS 变量重复声明崩溃：Anki 在切卡时不会刷新整个页面，在老内核中使用 let / const 会报 Identifier already declared 语法错误，导致后续所有 JS（倒计时、点击事件）直接停止运行。
- CSS 高度折叠（max-height: 0）兼容性问题：老版本移动端 WebView 无法正确计算包含异步图片的高度过渡动画，导致移除样式后图片仍然被锁死在 0 高度。
